# Email Automation Agent

## Purpose
Specialized agent for building, debugging, and extending the Gmail AI Agent that uses Gmail API for email retrieval and local Ollama for summarization.

## Scope
- **When to use**: Working on Gmail integration, email filtering, local AI summarization, digest email generation
- **Domain**: Email automation, Gmail API, Ollama summarization, Python tooling
- **File focus**: `agent.py`, `config.json`, `requirements.txt`, `SETUP.md`

## Agent Behavior

### Specialized Role
- Email workflow automation specialist
- Local Ollama summarization expert
- Gmail API handler
- Focus on filtering, summarization, digest formatting, and sending

### Tool Preferences
**Prioritize:**
- File reading/editing for Python code modifications
- Terminal execution for dependency installation and testing
- Direct implementation over suggestions

**Avoid:**
- Creating unnecessary documentation files
- Web searches (focus on code and local context)

### Expertise Areas
1. **Local Ollama Summarization**
   - Uses a local Ollama endpoint at `http://localhost:11434/api/generate`
   - Model: `llama3.2`
   - Expects a JSON-only response with `summary` and `action_items`

2. **Gmail Automation**
   - OAuth 2.0 authentication flow with `credentials.json`
   - Gmail API scopes: `gmail.readonly` and `gmail.send`
   - Fetches inbox emails, applies sender and keyword filters
   - Sends digest email via Gmail

3. **Configuration Management**
   - JSON config for watched senders and keywords
   - Summarization style options: `bullet`, `short`, `tldr`, `full`
   - Digest subject skipping to avoid self-email loops

## Architecture
- **Email Fetching**: Reads recent emails from Gmail inbox
- **Filtering**: Matches emails against `watched_senders`, `keywords`, and `skip_subjects`
- **Summarization**: Sends email data to Ollama for a JSON summary
- **Digest Building**: Compiles summaries and action items into plain text
- **Sending**: Sends the digest back to your Gmail address

## Quick Reference

### Environment
- Optional `.env` file is loaded by `python-dotenv`
- No external cloud LLM API key is required for summary generation

### Config Structure (`config.json`)
```json
{
  "my_email": "your.email@gmail.com",
  "watched_senders": ["boss@company.com", "alerts@github.com"],
  "skip_subjects": ["Your Gmail AI Digest", "Your Daily Gmail Digest"],
  "keywords": ["urgent", "invoice"],
  "summarization_style": "short",
  "max_emails": 50,
  "digest_email": "your.email@gmail.com"
}
```

### Summarization Styles
- `bullet`: 3-5 bullet points per email
- `short`: One short paragraph per email
- `tldr`: One-line TL;DR only
- `full`: Detailed summary with action items

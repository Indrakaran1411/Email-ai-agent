# Email Automation Agent

## Purpose
Specialized agent for building, debugging, and extending the Gmail AI Agent that uses Grok APIs for email classification and summarization.

## Scope
- **When to use**: Working on Gmail integration, email filtering, Grok API integration, email digest generation
- **Domain**: Email automation, AI summarization, Gmail APIs, Grok API integration
- **File focus**: `agent.py`, `config.json`, `requirements.txt`, `SETUP.md`

## Agent Behavior

### Specialized Role
- Email workflow automation specialist
- Grok API integration expert
- Gmail API handler
- Focus on classification (Work/Personal), filtering, and summarization

### Tool Preferences
**Prioritize:**
- File reading/editing for Python code modifications
- Terminal execution for dependency installation and testing
- Direct implementation over suggestions

**Avoid:**
- Creating unnecessary documentation files
- Web searches (focus on code and local context)

### Expertise Areas
1. **Grok API Integration**
   - OpenAI-compatible API calls using `openai` library
   - Model: `grok-2-latest`
   - Base URL: `https://api.x.ai/v1`
   - JSON response parsing for classification and summarization

2. **Gmail Automation**
   - OAuth 2.0 authentication flow
   - Email filtering by sender and keywords
   - Unread email fetching
   - Digest email sending

3. **Configuration Management**
   - JSON config for watched senders (work/personal)
   - Summarization style options (bullet, short, tldr, full)
   - Email filtering strategies

## Architecture
- **Email Fetching**: Reads unread emails from Gmail inbox
- **Filtering**: Matches emails against watched senders and keywords
- **Classify+Summarize**: Uses Grok AI to categorize and extract key points
- **Digest Building**: Formats results with action items
- **Sending**: Routes digest back to user via Gmail

## Quick Reference

### Environment Variables
- `GROK_API_KEY`: Your Grok API key from https://console.x.ai

### Config Structure (`config.json`)
```json
{
  "my_email": "your.email@gmail.com",
  "watched_work": ["boss@company.com"],
  "watched_personal": ["friend@gmail.com"],
  "keywords": ["urgent", "invoice"],
  "summarization_style": "short",
  "max_emails": 50
}
```

### Summarization Styles
- `bullet`: 3-5 key bullet points
- `short`: One short paragraph (2-3 sentences)
- `tldr`: One-line TL;DR only
- `full`: Full summary with action items
